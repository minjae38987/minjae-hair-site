## 민재 개인별 경쟁 직접성 분석(정량 성과 순위 아님)
1. **민정**: 시스루·숏가일·필러스·직모 문제 해결 메시지와 겹침. 단순 '손질 쉬운 머리'는 차별화 어려움.
2. **곤**: 필러스·드롭·가일 스타일과 두상/모질별 설계 메시지가 겹침. 숏 남성 스타일 고객 선택 경쟁.
3. **서인**: 남성 1:1 상담·모질/두상/손질법 약속이 거의 동일. 상담의 실제 검사 단계/전후 결과 증명이 필요.
4. **김유민**: 드롭·다운펌·볼륨매직으로 스타일 영역이 겹침. 포트폴리오 이미지와 실제 상담 사례 비교 필요.
5. **이승훈**: 리프·필러스·다운펌, 상담 강조가 겹치고 개별 당근 프로필도 운영. 채널/리뷰 플랫폼 혼용 금지.
6. **써니**: 개인 링크 허브의 전환 동선 비교대상. 실제 스타일 직접성은 보류.

위 순서는 **프로필 문구의 중첩 정도에 대한 정성적 분류**이며 예약시장 점유, 시술 실력, 실제 고객 수의 순위가 아님.

## 전략적 결론
'두상·모질 맞춤 상담'과 '손질 편리'는 여러 개인이 이미 강조한다. 민재가 검증 가능한 차별성을 만들려면
- (1) 옆머리 모류/길이 평가 → 커트만으로 가능한지 vs 다운펌 필요 이유 설명
- (2) 볼륨 저하 → 커트/펌 선택 근거와 실제 같은 각도 전후 비교
- (3) 원했던 사진과 실제 모질 차이 → 고객에게 미리 안내한 길이/실루엣과 완료 결과의 연결
을 고객 동의가 있는 **실제 사례** 단위로 기록한다. '타인이 못하는 기술'이라고 단정하지 않는다.
