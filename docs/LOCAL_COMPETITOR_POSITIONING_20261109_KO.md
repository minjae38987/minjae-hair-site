## 공통 표현과 차별화 가능성
**포화된 표현(단독 주장만으로 약함):**
- 두상·모질 맞춤
- 1:1 상담
- 남자머리 전문
- 손질이 편한 디자인
- 친절하고 꼼꼼한 시술

**검증하면 강력해질 수 있는 차별화 방향(아직 가설):**
1. '뜨는 옆머리'에서 **커트만으로 가능한 부분 / 다운펌이 필요한 부분**을 비교하는 실제 상담 사례.
2. '볼륨 없는 직모'에서 **커트 선택 기준 / 펌이 필요한 이유**를 실제 과정·전후 사진에 연결.
3. '스타일 실패 불안' 고객에게 **참고 사진과 고객 모발 상태의 차이**를 설명하고 최종 길이·측면 실루엣의 결과를 증명.
4. 같은 고객 문제별로 **시술 전 → 판단 근거 → 시술 결과 → 손질법**의 동일 문법을 사용하되, 실제 결과 없는 과장 금지.
