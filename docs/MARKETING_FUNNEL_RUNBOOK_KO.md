# 신규 고객 퍼널 측정 운영 기준 (2026-11-09)

## 목적
교육의 원칙인 **고객 입장 → 채널별 발견 → 실효성 확인 → 지정예약 → 유료 신규 방문**을 실제 데이터로 점검합니다. 게시·조회는 중간 지표이며 최종 KPI는 *실제 결제한 유료 신규 고객*입니다.

## 현재 재사용할 기능
- 홈페이지: `assets/booking-analytics.js`, `assets/ga4-consent.js`, 기존 GA4·SEO 테스트
- ChatCut 저장소 `minjae38987/-2`: 기존 영상 생성·iOS 렌더 QA. 이 보고서에서 자동 영상 게시를 실행하지 않습니다.
- Google Drive: 고객별 원본·블로그 승인 방식 유지. 미승인 글 자동 발행 금지.
- GA4 `naver_booking_click`: 네이버 예약 링크 클릭 **의도**만 측정. 예약 완료·유료 방문으로 표시하면 안 됩니다.

## 작업 방법
1. `marketing/funnel-input-template.csv`를 복사하여 날짜별로 작성합니다. 한 행은 **하루 × 유입 채널**의 합계입니다.
2. 노출·클릭 데이터는 해당 SNS/웹 채널에서 가져옵니다. 접근 불가하면 함부로 0으로 채우지 않고 수집 불가 항목을 별도 기록합니다.
3. 확정 예약은 네이버 예약에서, **유료 신규 방문**은 실제 매장 집계에서 확인합니다.
4. 고객이 어디서 발견했는지 불명확하면 채널을 `unknown`으로 분류합니다. 중복 추적할 수 없다면 고객을 여러 채널에 중복 계산하지 마세요.
5. 실행: `python3 scripts/marketing_funnel_report.py --input marketing/funnel-input-template.csv --output output/marketing-funnel-report.md --target 100`
6. 주 단위로 노출 부족 / 클릭 부족 / 예약 부족 / 유료 방문 부족을 나누어 개선합니다.

## 콘텐츠 제작 전 필수 기획 항목
- 고객 유형 / 실제 고객 고민 / 검증된 시술 사례 / 콘텐츠가 제공하는 정보 / 유입 채널 / 예약 유도 방법 / 최종 측정 지표
- 실제 고객의 동의가 없는 영상·개인정보 업로드 금지, 효과나 후기 조작 금지
- 인스타그램 해시태그 5개 원칙과 고화질 iOS 호환 영상 검증 유지
- ChatCut / 블로그 / 네이버 플레이스는 **최종 승인 후** 게시

## 데이터 한계
비율은 **이벤트 건수 기반 참고치**입니다. 동일한 사람의 기기/채널 이동을 식별하지 않으며, 결제 고객은 별도 대조가 필요합니다. GA4만으로 신규 고객 100명 달성을 증명할 수 없습니다.
