# 민재 헤어 홈페이지 SEO 코드 점검 — 2026-11-07

검사 대상: https://minjae38987.github.io/minjae-hair-site/
분석 방식: 연결된 GitHub 원본 index.html, robots.txt, sitemap.xml 정적 검사. 실제 Google 검색 순위·색인·Core Web Vitals·Blogger 게시 상태는 측정하지 않음.

## 확인된 사항
- title: `민재 디자이너 | 서울대입구 남자머리·다운펌 | 에이점헤어`
- meta description: 존재. 지역/주요 시술/네이버 지정예약 포함
- canonical: 홈 URL로 지정됨
- robots.txt: 전체 크롤러 Allow, sitemap 경로 존재
- sitemap.xml: XML 문서에 홈페이지 URL 1개 포함
- H1: 1개 (`손질까지 설계하는 남자머리.`)
- JSON-LD: 2블록 (내용·Google 적합성 별도 검증 필요)
- 네이버 예약 링크: HTML 소스에서 3개
- Blogger/Blogspot 링크: HTML 소스에서 0개
- `<img>` 요소: 0개. Instagram iframe 중심의 포트폴리오 구성
- iframe: 11개. 페이지 속도/접근성·크롤러가 볼 수 있는 콘텐츠에 관한 실측 필요

## 우선순위별 조치
1. **P1: Blogger 게시 글의 영구 URL을 확인한 뒤**, 홈페이지에서 실제 글로 연결되는 링크 추가. 존재하지 않는 Blogger 주소를 만들어 삽입하지 말 것.
2. **P1: 릴스 중심 페이지의 텍스트 설명과 시술별 실제 사진**을 보강. 사용자 경험과 검색 엔진이 이해할 수 있는 직접 콘텐츠 확보.
3. **P2: Instagram iframe 11개의 모바일 로드 비용**을 PageSpeed Insights/실기기에서 측정. 성능 저하 확인 전 임의로 콘텐츠 제거하지 말 것.
4. **P2: 구조화 데이터 2블록**의 JSON 파싱과 페이지 표시 내용 일치 여부 검사. 증명되지 않은 평점·시술 횟수 추가 금지.
5. **P2: Search Console의 sitemap '가져올 수 없음' 표시**는 XML 파일이 정상이라는 사실과 별개. Search Console 상태를 확인하고 추이를 추적하며 반복적인 재제출은 지양.
6. **P3: 실제 검색 노출/클릭/예약 연결**에 기반한 효과 평가. SEO 지표 개선을 순위 상승이나 예약 증가로 단정하지 말 것.
